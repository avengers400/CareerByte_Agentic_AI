# Module 1 — Python Foundations

Module 1 introduces Python programming through short lessons and operations-themed examples. The material moves from core language building blocks to reusable functions, error handling, file I/O, and object-oriented programming.

## Topics

- [Python course material](PYTHON/README.md) — the complete learning path and execution notes.
- [Data types and input](PYTHON/1-datatypes/README.md) — variables, types, operators, conversions, user input, and a small server report.
- [Conditions and collections](PYTHON/2-statements-loops-list-dict-set-tuple.py/README.md) — branching, boolean expressions, loops, lists, dictionaries, tuples, and sets.
- [Functions](PYTHON/3-functions/README.md) — function definitions, arguments, return values, lambdas, higher-order functions, docstrings, and JSON conversion.
- [Error handling](PYTHON/error-handling/README.md) — `try`/`except`/`finally` and common runtime errors.
- [File reading and writing](PYTHON/file-reading-writing/README.md) — text and JSON file examples and their sample data.
- [Object-oriented programming](PYTHON/oops/README.md) — classes, objects, attributes, inheritance, overriding, and method types.

## Suggested approach

Follow the folders in the order shown above. Read each script, predict its output, and then run it. Treat the examples as standalone exercises: each script may reuse common names such as `server`, but it does not depend on running the previous script.

For prerequisites and examples of running the material, see the [Python module README](PYTHON/README.md).
