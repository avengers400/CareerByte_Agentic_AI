## Core concepts in this module

The lessons build from **values and control flow** to **reusable and organized programs**:

- **Data and types:** A program stores information in values such as text, whole numbers, decimals, and true/false values. Types determine which operations make sense for those values.
- **Control flow:** Conditions let a program choose what to do; loops repeat work over a sequence of values.
- **Collections:** Lists, tuples, sets, and dictionaries group related data, each with different rules for ordering, uniqueness, mutability, and lookup.
- **Functions:** Functions package a task behind a name, accept inputs, and can return results for other parts of a program to use.
- **Errors and files:** Exceptions let a program handle failures deliberately, while file operations let it read and save information beyond the lifetime of one run.
- **Objects and classes:** Classes bring related data and behavior together; objects are individual instances used to represent entities such as servers.
